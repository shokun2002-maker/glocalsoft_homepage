# 영광소리 CMS & 신문사 SaaS 실제 화면 에셋 보관함

이 디렉토리는 `/newspaper/` 소개 페이지의 [쇼케이스] 섹션에 사용되는 실제 서비스 스크린샷 이미지들을 관리하는 곳입니다.

---

## 1. Area A: 독자에게 보이는 신문사 홈페이지 (실서비스 적용 완료)

영광소리(ygsori.com)의 실제 운영 서비스에서 캡처하여 적용 완료된 4개 화면입니다.

1. `ygsori-pc-homepage.png` (1280x2800)
   - 영광소리 정식 서비스 중인 PC 독자용 메인 포털 화면
   - 헤드라인, 주요 기사, 다단 카테고리, 긴급 속보 바 등 정통 지역 정론지 표준 레이아웃

2. `ygsori-mobile-homepage.png` (390x2800)
   - 스마트폰 모바일 브라우저 최적화 독자 뷰
   - 모바일 상단 메인 광고 배너 및 기사 터치 카드 반응형 최적화

3. `ygsori-article-detail.png` (1280x2500)
   - 정론지 표준 기사 본문 양쪽 정렬(Justify) 및 마지막 줄 좌측 정렬 규칙 적용 화면
   - 기자 실명 바이라인 프로필, 본문형 문맥 광고 연동 실제 뷰

4. `ygsori-live-ads-pc.png` (1280x1200)
   - 영광소리 실제 지면에 게재된 1200x200 와이드 헤더 축제 광고 배너 및 4:3 사이드 광고 배치 화면

---

## 2. Area B: 신문사를 운영하는 AI 통합 관리자 (공개용 마스킹 파일 전용)

보안 지침에 따라 **원본 관리자 스크린샷(`admin-*.png`)은 웹사이트 assets에 직접 노출되지 않으며 Git 커밋에서 원천 제외(`/.gitignore`)**됩니다.

오직 **브라우저 탭/주소창 크롭 및 개인정보·비공개 기사 픽셀 마스킹이 완료된 공개용 파일(`public-admin-*.png`)**만 이 디렉토리에 배치되어 웹사이트에 로드됩니다:

1. `public-admin-ai-writer.png` (AI 기사 작성실)
   - 취재 내용을 AI와 대화하며 정리하고 기사 초안을 작성하는 실제 화면
2. `public-admin-inbox.png` (AI 보도자료 자동화)
   - 이메일로 수신한 보도자료와 사진을 분석하고 기사 작성부터 일괄발행까지 지원하는 실제 화면
3. `public-admin-social.png` (SNS 통합배포센터)
   - 발행 기사를 SNS 채널별로 편집하고 배포 작업을 관리하는 실제 화면
4. `public-admin-dashboard.png` (통합 관리자 대시보드)
   - 기사와 광고, 발행 및 운영 업무를 하나의 시스템에서 관리하는 실제 화면
5. `public-admin-kakao-share.png` (카카오톡 뉴스 공유)
   - 기사별 카카오톡 공유 카드와 공유 작업을 지원하는 실제 화면

*파일 로딩 순서: `public-admin-*.png` → 이미지 미등록 플레이스홀더 (원본 fallback 없음)*

---

## 3. ⚠️ 보안 및 개인정보 마스킹 지침 (엄격 준수)

- **브라우저 요소 제거**: 상단 탭, URL 주소창, 북마크 바를 크롭하여 CMS 내부 영역만 노출합니다.
- **내부 개인정보 마스킹**: 취재원 연락처, 제보자 개인정보, 기자 개인 이메일/전화번호는 불투명 박스로 완전히 덮어 픽셀 데이터를 영구 제거합니다.
- **관리자 인증 기밀 보호**: 관리자 계정 ID, 비밀번호, Supabase API Key, 내부 세션 토큰 등이 포함된 영역은 완전히 삭제하거나 가립니다.
- **비공개 기사 보호**: 내부 검토 중인 미발행 기사, 비공개 취재 메모, 대외비 통계는 공개 화면에서 제외하거나 마스킹합니다.
- **권장 해상도**: 가로 1200px ~ 1600px, 16:9 또는 16:10 비율, WebP 또는 압축된 PNG 포맷.
